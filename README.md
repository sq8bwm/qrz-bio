Obrazki do biografii QRZ.com SQ8BWM i SQ8BWA: dyplomy, karty QSL i ich miniatury, podawane przez GitHub Pages (HTTPS).

- `dyplomy/<grupa>/min/` — thumbnails shown in the gallery
- `inne/` — logos and other images
